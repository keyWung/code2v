# 代码画物理 EP05：电场线

Remotion + React + TypeScript，竖屏 1080x1920 / 30fps / 60 秒（1800 帧，6 镜）。

- 数据唯一来源：`episodes/ep05-dianchangxian.json`
- 配色唯一来源：`src/theme.ts`，色值与 EP01 完全一致（`npm run verify` 会比对）
- 场强都由 JSON 里那行代码现算：`const E = k * Q / (r * r)`（`src/physics.ts` 的 `fieldE()`，`verify` 会拿 JSON 原句逐点比对）；k、Q 从 JSON 的 conditions 里读
- 场强箭头长度与 E 成正比：0.1 米处 100 像素，0.2 米处 25 像素
- 两个电荷的图：每个点电荷都按 `fieldE()` 算，矢量相加（`fieldAt()`），再沿场强方向一步步描出电场线；`verify` 检查每一点切线都与场强一致、任意两条线不相交、同种电荷连线中点场强为零
- 镜 5 粒子轨迹：带正电的粒子在拱形电场线的顶点从静止释放，按 a ∝ E 积分；从静止出发时轨迹形状与荷质比无关

## 和规划 JSON 的一处不同

- 镜 6 口播原句“下一期，波的干涉：为什么两列波叠加，有的地方更强，有的地方更弱？”按全片统一语速要说 5.15 秒，这一镜只能放 4.62 秒（再长会被片尾截断）。改成“下一期波的干涉：为什么两列波叠加，有的更强，有的更弱？”，说完 4.17 秒。字幕不受影响。

## 常用命令

```bash
npm run studio   # 浏览器里预览、拖时间轴（带口播）
npm run verify   # 自查清单：三组数字、代码来源、切线与不相交、模型与边缘效应说法、分镜帧、盖章、章节进度、遮挡区、颜色来源
npm run vo       # 重新生成 public/vo/*.wav（默认微软「云希」男声，全片统一 1.18 倍速）
npm run dub      # 只换配音：口播合进无配音版画面，几秒完成
npm run stills   # 渲染关键帧到 out/frames/，加 --safe 叠加平台遮挡区
npm run render   # 重渲画面：成片、无配音版、封面、字幕全部输出到 out/
```

## 沿用前几期踩过的坑

- **冻结段闪烁**：弹簧动画 40 帧后定格为精确的 1（`settle`），不动画字号；列表 key 一律用唯一编号；`render` 每次都逐字节比对 1650–1799 帧，不一致就停下、不出片。
- **语速前后不一**：`vo` 只用一个语速，按最后一个字说完的时间判断放不放得下；放不下就报错，请精简 JSON 口播。
- **口播里的数字念法**：`vo` 只在送去合成前把“9.0×10^5”换成“9.0乘10的5次方”、“1/4”换成“4分之1”，JSON 和字幕不动。
- **macOS 13 跑不了 Remotion 自带 ffmpeg**：`render` 先出 JPEG 序列，再用 `ffmpeg-static` 编码和混音。
- **edge-tts 不走系统代理**：脚本显式传 `HTTPS_PROXY`，断线自动重试；口播文字会发到微软服务器。
- **渲染用的 Chrome 下载很慢**：已放在 `node_modules/.remotion/`（从 EP04 克隆）。重装依赖后若卡住，见 EP02 README 的手动下载步骤。
- **线的疏密只看趋势**：平面图上的线间距不严格按 1/r² 变，所以片中不拿线间距去推 1/4，1/4 只从公式算；条数用“画 8 条、24 条也行”演示是人定的。
- **两种箭头叠在一起**：画了绿色场强箭头的那几条线，线上自带的方向箭头会收起来。
- **单个电荷的线是直的**：镜 2 放大镜里切线和场强本来就重合；镜 5 在弯曲的偶极子电场线上再画一次切线方向的场强箭头。
- **遮挡区**：舞台、四格、所有箭头和粒子轨迹都在右侧互动栏和底部操作栏之外；`verify` 会逐个检查。
- **封面裁切**：9:16 封面的内容放在中间 1440 高的区域，主页裁成 3:4 时不会被切掉。
